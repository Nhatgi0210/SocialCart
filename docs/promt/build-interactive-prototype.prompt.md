# P4.4 — Xây prototype SocialCart

Đầu ra [prototype](../../prototype/): index.html, styles.css, mock-data.js, app.js. Kiểm tra source hiện có trước khi sửa. Giữ Concept B và interaction contract: login → inbox/filter → chat → AI/handoff → gửi/retry → tạo đơn. Dependency-free, backend-free, state reset khi reload; biểu diễn lỗi mô phỏng rõ. Kiểm keyboard/focus/modal, mobile và reduced motion. Không biến mock thành bằng chứng backend. Người dùng review trước khi coi prototype là accepted reference.


Đọc [AGENTS](../../AGENTS.md), [decision log](../decisions.md), [design brief](../product-design-brief.md), [product design](../product-design.md). Các skill thiết kế ngoài repository chỉ dùng nếu thực sự có sẵn, không coi tên skill trong template cũ là dependency bắt buộc. Giữ phạm vi SocialCart; không thêm register, ticket board, Kanban hoặc backend vào prototype.
